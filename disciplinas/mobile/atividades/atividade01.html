Atividade Prática 01: To-do App com Flutter

⏰ 2 aulas (100 min) Valor: 2,0 pontos
⚠ Atividade individual ou em duplas. Entregar link do repositório GitHub.

Objetivo

Criar um aplicativo de lista de tarefas (to-do list) usando Flutter, aplicando widgets fundamentais, estado e navegação.

Requisitos

Funcionalidades (60%)

  • Tela principal com lista de tarefas
  • Adicionar nova tarefa (com formulário ou dialog)
  • Marcar tarefa como concluída (checkbox)
  • Remover tarefa (deslizar ou botão de exclusão)
  • Persistência local com SharedPreferences

Interface (25%)

  • Material Design com tema personalizado (cores, fontes)
  • ListView com itens bem estruturados (título, data, status)
  • Empty state quando não houver tarefas ("Nenhuma tarefa ainda")
  • Snackbar para feedback (ex: "Tarefa removida")

Código (15%)

  • Componentização (widgets separados)
  • Estado gerenciado com StatefulWidget ou Provider
  • Código limpo e organizado

Estrutura Sugerida

lib/
  main.dart
  models/
    tarefa.dart
  screens/
    home_screen.dart
  widgets/
    tarefa_item.dart
    formulario_dialog.dart

Entrega

  • README com instruções e screenshots
  • Data: conforme calendário
