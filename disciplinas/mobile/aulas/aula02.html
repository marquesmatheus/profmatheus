Aula 02: Introdução ao Flutter e Dart

⏰ 50 min

O que é Flutter?

Flutter é um framework de UI criado pelo Google para construir aplicações compiladas nativamente para múltiplas plataformas a partir de uma única base de código. Foi lançado em 2017 e usa a linguagem Dart.

O que é Dart?

Dart é uma linguagem de programação moderna, orientada a objetos e com sintaxe familiar a desenvolvedores Java/JavaScript/C#. Características:

  • Compilada (AOT para produção, JIT para desenvolvimento)
  • Tipagem forte e opcional
  • Null safety (sem null pointer exceptions inesperadas)
  • Programação assíncrona nativa (async/await)
  • Garbage collector

Primeiro Projeto Flutter

flutter create meu_app
cd meu_app
flutter run

Estrutura de pastas gerada:

  • lib/main.dart — Código principal da aplicação
  • android/ — Configuração do Android
  • ios/ — Configuração do iOS
  • pubspec.yaml — Gerenciamento de dependências

Entendendo o main.dart

import 'package:flutter/material.dart';

void main() {
  runApp(const MeuApp());
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Meu App')),
        body: const Center(
          child: Text('Olá, Flutter!'),
        ),
      ),
    );
  }
}

Explicação:

  • void main() — Ponto de entrada do app
  • runApp() — Inicializa o Flutter com o widget raiz
  • StatelessWidget — Widget imutável (não muda de estado)
  • MaterialApp — Configuração do tema Material Design
  • Scaffold — Estrutura visual básica de tela
  • AppBar — Barra superior
  • Text — Widget de texto

Executando e modificando

Com o app rodando (flutter run), edite o texto no main.dart e salve. O Hot Reload atualizará o app instantaneamente sem perder o estado.

Dica: No terminal, pressione r para hot reload, R para hot restart.

Exercícios

  1. Crie um novo projeto Flutter com flutter create.
  2. Modifique o texto "Olá, Flutter!" para seu nome.
  3. Altere a cor do AppBar para azul (Colors.blue).
  4. Adicione um ícone (Icon widget) abaixo do texto.
