Aula 01: Plataformas Móveis e Ecossistema

⏰ 50 min

O Mercado Mobile

O desenvolvimento mobile é um dos maiores mercados de tecnologia. Dados atuais:

  • Mais de 6,5 bilhões de smartphones no mundo
  • Google Play: ~3,5 milhões de apps
  • Apple App Store: ~1,6 milhão de apps
  • Brasil: 1 smartphone por habitante (mais de 240 milhões)

Plataformas Nativas

Android

  • Linguagem: Kotlin (oficial), Java
  • IDE: Android Studio
  • Kernel: Linux modificado
  • Runtime: ART (Android Runtime)
  • Publish: Google Play Store

iOS

  • Linguagem: Swift (oficial), Objective-C
  • IDE: Xcode (exclusivo macOS)
  • Kernel: XNU (híbrido)
  • Publish: Apple App Store

Desenvolvimento Cross-Platform

Alternativa ao desenvolvimento nativo — escreve uma vez e publica em ambas plataformas:

Flutter (Google)

  • Linguagem: Dart
  • Renderização: Skia (próprio motor gráfico)
  • Performance: Próxima ao nativo (60/120 fps)
  • Público-alvo: Android, iOS, Web, Desktop

React Native (Meta)

  • Linguagem: JavaScript/TypeScript
  • Renderização: Ponte nativa (bridge)
  • Reutilização: Componentes React

Outras opções

  • Xamarin (Microsoft) — C#
  • Ionic/Cordova — WebView
  • Kotlin Multiplatform — Código compartilhado + nativo

Por que Flutter?

Neste curso usaremos Flutter porque:

  • Performance nativa sem bridge
  • Hot Reload para desenvolvimento rápido
  • Widgets bonitos e customizáveis (Material Design + Cupertino)
  • Uma base de código para múltiplas plataformas
  • Comunidade crescente e forte suporte do Google

Instalação do Ambiente

Para a próxima aula, instale:

  1. Flutter SDK: flutter.dev
  2. Editor: VS Code ou Android Studio
  3. Extensão Flutter no VS Code
  4. Android Emulator ou dispositivo físico
Rode flutter doctor no terminal para verificar se tudo está configurado corretamente.

Exercícios

  1. Explique a diferença entre desenvolvimento nativo e cross-platform.
  2. Por que o Flutter não usa uma WebView para renderizar?
  3. Pesquise: o que é Hot Reload e por que é útil?
  4. Instale o Flutter e rode flutter doctor — anote quais itens estão OK e quais faltam.
