Atividade Prática 01: Threads e Sincronização

⏰ 2 aulas (100 min) Valor: 2,0 pontos
⚠ Esta atividade deve ser feita em duplas. Entregar código + relatório (PDF).

Objetivo

Implementar um programa concorrente em C ou Python que cria múltiplas threads e utiliza mecanismos de sincronização.

Parte 1: Criação de Threads

Escreva um programa que crie 5 threads. Cada thread deve imprimir seu ID e o número da iteração (de 1 a 10), com um pequeno atraso aleatório entre impressões.

Exemplo em C (pthreads)

#include <stdio.h>
#include <pthread.h>
#include <unistd.h>

void* tarefa(void* arg) {
    int id = *(int*)arg;
    for (int i = 1; i <= 10; i++) {
        printf("Thread %d: iteração %d\n", id, i);
        usleep(100000); // 100ms
    }
    return NULL;
}

int main() {
    pthread_t threads[5];
    int ids[5];
    for (int i = 0; i < 5; i++) {
        ids[i] = i + 1;
        pthread_create(&threads[i], NULL, tarefa, &ids[i]);
    }
    for (int i = 0; i < 5; i++)
        pthread_join(threads[i], NULL);
    return 0;
}

Parte 2: Sincronização com Mutex

Modifique o programa anterior para que todas as threads compartilhem uma variável contador global. Cada thread deve incrementar o contador 1000 vezes. Use um mutex para garantir exclusão mútua. Ao final, o valor do contador deve ser 5000 (5 threads x 1000).

Parte 3: Problema Produtor-Consumidor

Implemente o problema produtor-consumidor com buffer de tamanho 5:

  • 2 threads produtoras: produzem itens (números inteiros) a cada 200ms
  • 3 threads consumidoras: consomem itens a cada 300ms
  • Use semáforos para controlar o acesso ao buffer
  • Produtores devem esperar se buffer estiver cheio
  • Consumidores devem esperar se buffer estiver vazio
