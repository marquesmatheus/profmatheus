Aula 01: Conceitos Básicos e Evolução dos SO

⏰ 50 min

O que é um Sistema Operacional?

Um Sistema Operacional (SO) é um software que atua como intermediário entre o hardware do computador e os programas do usuário. Seus principais objetivos são:

  • Gerenciar recursos do hardware (CPU, memória, disco, E/S)
  • Prover uma interface para o usuário interagir com o computador
  • Executar programas de forma eficiente e isolada
  • Garantir segurança e proteção entre processos

Evolução Histórica

1ª Geração (1945-1955) — Válvulas

Programação em painel de conectores e cartões perfurados. Sem SO. Operação manual com grande desperdício de tempo de CPU.

2ª Geração (1955-1965) — Transistores e Batch

Surgem os primeiros sistemas batch (lote). Programas eram perfurados em cartões e processados em lote sem interação do usuário. Surge o monitor residente (primeiro esboço de SO).

3ª Geração (1965-1980) — Circuitos Integrados e Multiprogramação

IBM System/360. Surge o conceito de multiprogramação: vários programas na memória ao mesmo tempo, enquanto um espera E/S, outro executa. Surgem também o tempo compartilhado (time-sharing) com o CTSS e Multics.

4ª Geração (1980-hoje) — Microcomputadores

Surgimento dos PCs. MS-DOS (Microsoft), MacOS (Apple). Interfaces gráficas (GUI). Unix se populariza (Linux, BSD). SO modernos: Windows, Linux, macOS, Android, iOS.

Tipos de SO

  • Batch: Processamento em lote, sem interação (ex: mainframes antigos)
  • Tempo Compartilhado: CPU alterna entre usuários rapidamente (ex: Unix)
  • Distribuído: Múltiplas máquinas trabalham como um sistema único
  • Tempo Real: Resposta em tempo determinístico (ex: FreeRTOS)
  • Embarcado: Dispositivos dedicados (ex: IoT, Arduino)

Componentes de um SO

  • Kernel (núcleo): Parte central do SO, gerencia processos, memória, dispositivos
  • Shell/Interface: CLI (terminal) ou GUI (ambiente gráfico)
  • System calls: Interface entre programas e kernel
  • Utilitários: Programas auxiliares (compiladores, editores, etc.)
