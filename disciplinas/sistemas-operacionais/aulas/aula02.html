Aula 02: Estrutura de Sistemas Computacionais

⏰ 50 min

Organização Básica do Computador

Um sistema computacional é composto por:

  • CPU (Processador): Executa instruções — busca (fetch), decodifica e executa
  • Memória principal (RAM): Armazena dados e instruções em execução — volátil
  • Dispositivos de E/S: Teclado, mouse, monitor, disco, rede
  • Barramento: Conexão entre os componentes (dados, endereço, controle)

Modos de Operação

Para proteger o sistema, a CPU opera em dois modos:

  • Modo Kernel (privilegiado): Acesso total ao hardware. Executa o núcleo do SO.
  • Modo Usuário: Acesso restrito. Programas do usuário rodam neste modo.
Uma instrução privilegiada (ex: alterar registrador de modo, gerenciar memória) só pode ser executada no modo kernel. Se um programa de usuário tentar, ocorre uma exceção (trap).

Interrupções

Mecanismo pelo qual o hardware notifica o SO sobre eventos:

  • Interrupções de hardware: Dispositivos de E/S, timer
  • Exceptions (traps): Erros de programa (divisão por zero), system calls

Quando ocorre uma interrupção, a CPU salva o contexto atual, executa o handler da interrupção (via tabela de vetores de interrupção), e retorna ao programa interrompido.

Chamadas de Sistema (System Calls)

Interface entre os programas do usuário e o kernel. O programa solicita um serviço ao SO:

  • Manipulação de arquivos (open, read, write, close)
  • Gerência de processos (fork, exec, wait, exit)
  • Comunicação (pipe, shmget, socket)
  • Informações do sistema (getpid, time)

Exemplo em C:

#include <unistd.h>
#include <stdio.h>

int main() {
    write(STDOUT_FILENO, "Olá, mundo!\n", 12);
    return 0;
}

A função write() é uma chamada de sistema que solicita ao kernel que escreva no terminal.

Estrutura do Kernel

  • Monolítico: Todo o SO roda no kernel (Linux) — rápido, mas qualquer falha derruba o sistema
  • Micronúcleo: Kernel mínimo, serviços rodam em espaço de usuário (Minix, QNX) — estável, mas mais lento
  • Híbrido: Combina ambos (Windows, macOS)

Exercícios

  1. Explique a diferença entre modo usuário e modo kernel.
  2. O que acontece quando um programa faz uma chamada de sistema?
  3. Qual a vantagem de um kernel monolítico sobre um micronúcleo? E a desvantagem?
  4. Pesquise: o que é o System Call Table no Linux?
