Atividade Prática 01: Análise de Pacotes com Wireshark

⏰ 2 aulas (100 min) Valor: 2,0 pontos
⚠ Instale o Wireshark antes da aula. Atividade individual.

Objetivo

Utilizar o Wireshark para capturar e analisar pacotes TCP/IP, identificando protocolos, cabeçalhos e fluxos de comunicação.

Parte 1: Captura Inicial

  1. Abra o Wireshark e inicie a captura na interface de rede ativa (Wi-Fi ou Ethernet)
  2. Acesse http://example.com no navegador
  3. Pare a captura
  4. Filtre por "http" ou "dns"

Parte 2: Análise de uma Requisição HTTP

  1. Localize um pacote GET no filtro HTTP
  2. Analise o cabeçalho da requisição (Request Line, Headers)
  3. Analise o cabeçalho da resposta (Status Line, Headers)
  4. Identifique os campos: User-Agent, Content-Type, Server

Parte 3: Handshake TCP

Filtre por "tcp.port == 80". Identifique os 3 pacotes do handshake TCP:

  • Pacote 1: SYN (Flag SYN=1, seq=x)
  • Pacote 2: SYN-ACK (SYN=1, ACK=1, seq=y, ack=x+1)
  • Pacote 3: ACK (ACK=1, seq=x+1, ack=y+1)

Anote os números de sequência e confirmação.

Parte 4: Consulta DNS

Filtre por "dns". Encontre uma consulta DNS e identifique:

  • Transaction ID
  • Query: nome do domínio consultado
  • Response: endereço IP retornado

Entrega

Relatório (PDF) contendo:

  • Screenshots da captura com explicações
  • Análise do handshake TCP (números de sequência)
  • Análise da requisição/resposta HTTP
  • Resposta da consulta DNS
