Atividade Prática 01: Landing Page Responsiva

⏰ 3 aulas (150 min) Valor: 3,0 pontos
⚠ Individual. Entregar link do GitHub Pages ou arquivo ZIP.

Objetivo

Criar uma landing page responsiva usando HTML, CSS e JavaScript, aplicando os conceitos vistos em aula.

Requisitos

HTML (30%)

  • DOCTYPE html5 e meta charset UTF-8
  • Tags semânticas: header, nav, main, section, footer
  • Formulário de contato com: nome, e-mail, mensagem
  • Links para redes sociais
  • Imagens com atributo alt

CSS (40%)

  • Layout responsivo usando Flexbox e/ou Grid
  • Media queries para mobile (até 600px), tablet (601-1024px), desktop (>1024px)
  • Paleta de cores consistente (definir no :root)
  • Navegação com hover e transições
  • Tipografia com fontes do Google Fonts

JavaScript (30%)

  • Menu mobile (hamburger) com toggle
  • Validação do formulário de contato (campos obrigatórios, formato de e-mail)
  • Exibir mensagem de sucesso ao enviar (sem recarregar a página)
  • Scroll suave para seções (smooth scroll)

Tema

Escolha UM dos temas abaixo:

  • Landing page de um produto/serviço fictício
  • Portfólio pessoal
  • Site de um evento acadêmico

Entrega

  • Repositório GitHub com GitHub Pages ativo
  • Ou arquivo ZIP com todos os arquivos
  • Data: conforme calendário
