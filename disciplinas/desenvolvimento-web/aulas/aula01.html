Aula 01: Como a Web Funciona

⏰ 50 min

O que é a Web?

A World Wide Web (WWW) é um sistema de documentos interligados acessíveis via Internet. Criada por Tim Berners-Lee em 1989 no CERN. Importante: Web ≠ Internet — a Internet é a infraestrutura de redes; a Web é um serviço que roda sobre ela.

Modelo Cliente-Servidor

  • Cliente: Navegador (Chrome, Firefox, Edge) que faz requisições
  • Servidor: Computador que hospeda e entrega os recursos (Apache, Nginx)
  • Cliente envia uma requisição HTTP, servidor retorna uma resposta HTTP

Componentes de uma URL

https://www.exemplo.com:443/caminho/recurso?q=busca#secao
  • Protocolo: https://
  • Domínio: www.exemplo.com
  • Porta: :443 (padrão HTTPS)
  • Caminho: /caminho/recurso
  • Query string: ?q=busca
  • Fragmento: #secao

DNS (Domain Name System)

Tradutor de nomes de domínio para endereços IP:

  1. Você digita "google.com" no navegador
  2. O navegador consulta o DNS para resolver o IP
  3. DNS retorna 142.250.218.78 (exemplo)
  4. Navegador faz requisição HTTP para esse IP

HTTP

Protocolo de transferência de hipertexto. Baseado em requisição e resposta.

Métodos HTTP

  • GET: Recuperar um recurso
  • POST: Enviar dados para criar um recurso
  • PUT: Atualizar um recurso
  • DELETE: Remover um recurso
  • PATCH: Atualização parcial

Códigos de Status

  • 1xx: Informativo (101 Switching Protocols)
  • 2xx: Sucesso (200 OK, 201 Created)
  • 3xx: Redirecionamento (301 Moved Permanently, 304 Not Modified)
  • 4xx: Erro do cliente (404 Not Found, 403 Forbidden)
  • 5xx: Erro do servidor (500 Internal Server Error)

O Caminho de uma Requisição

  1. Usuário digita URL
  2. DNS resolve o endereço IP
  3. Conexão TCP é estabelecida (handshake de 3 vias)
  4. Requisição HTTP é enviada ao servidor
  5. Servidor processa e retorna a resposta
  6. Navegador renderiza o HTML, CSS e executa JS
Ferramenta: Abra o DevTools do navegador (F12) → aba Network. Recarregue a página e veja cada requisição feita.

HTML, CSS e JavaScript

  • HTML: Estrutura e conteúdo da página (esqueleto)
  • CSS: Estilo e aparência (roupas)
  • JavaScript: Comportamento e interação (movimento)

Exercícios

  1. Qual a diferença entre Internet e Web?
  2. Explique o papel do DNS.
  3. Qual a diferença entre GET e POST?
  4. Usando o DevTools, identifique 3 recursos carregados por uma página e seus códigos de status.
