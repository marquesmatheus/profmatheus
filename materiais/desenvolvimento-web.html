Exercícios e Listas

Listas compiladas com exercícios práticos de desenvolvimento web, do HTML ao deploy. Cada lista contém 4 exercícios com implementação em React + TypeScript, testes e integração com APIs.

Listas por Bloco
📝 Lista 1 — HTML, CSS e Fundamentos Web
Landing page para startup de delivery (HTML semântico, Flexbox, Grid, responsivo mobile-first), diagnóstico de problemas mobile (especificidade CSS, acessibilidade WCAG), animações com @keyframes e performance (reflow vs composição), publicação no GitHub Pages com PageSpeed Insights.
📝 Lista 2 — JavaScript e Manipulação do DOM
Calculadora de IMC com validação visual e arrow functions, dashboard de vendas com tabela dinâmica e event delegation, formulário de cadastro com CEP automático (ViaCEP) e async/await, carrinho de compras com localStorage e closures. Inclui event loop e Promises.
📝 Lista 3 — React e Componentes
Dashboard de rastreamento com filtros e busca (useState, props), formulário multi-etapas com validação e sessionStorage, lista infinita com IntersectionObserver e skeleton loader, tema escuro com Context API + useReducer. Inclui reconciliation e useEffect cleanup.
📝 Lista 4 — Estado, APIs e Roteamento
Weather app com OpenWeatherMap e useReducer, autenticação com AuthContext + React Router v6 e JWT, dashboard financeiro com hooks customizados (useFetch, useLocalStorage) e cache stale-while-revalidate, upload de produtos com preview e barra de progresso. Inclui AbortController.
📝 Lista 5 — TypeScript e Padrões Avançados
Refatoração React para TypeScript com Generics e interfaces, testes unitários e de integração (Vitest + Testing Library), padrões de projeto (Observer, Factory, Compound Components), PWA com Service Worker e cache. Inclui GitHub Actions para CI.
📝 Lista 6 — Projetos e Deploy
Projeto final de e-commerce completo com React + TS, CI/CD na Vercel com Docker multi-stage e GitHub Actions, otimização de performance (Core Web Vitals, Lighthouse, lazy loading, code splitting), monitoramento com Sentry e feature flags. Inclui testes E2E com Playwright.
