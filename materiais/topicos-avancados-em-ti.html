Exercícios e Listas

Listas compiladas com exercícios práticos sobre tecnologias emergentes. Cada lista contém 4 exercícios com implementação (Google Colab, Docker, Kubernetes), pesquisa acadêmica e análise de mercado.

Listas por Bloco
📝 Lista 1 — IA Generativa e Deep Learning
Previsão de demanda com ML para varejo (Hype Cycle, LLMs, RLHF), IA generativa para marketing com prompt engineering (few-shot, CoT, RAG, LoRA), CNN e transfer learning no Colab para classificação de imagens, revisão sistemática da literatura sobre LLMs na educação (IMRaD, ABNT). Inclui alucinação e benchmarks.
📝 Lista 2 — Cloud Native, DevOps e Microsserviços
Migração de monólito para microsserviços com DDD, Saga e API Gateway, CI/CD com Docker multi-stage e Kubernetes (Deployment, Service, ConfigMap), observabilidade com Prometheus, Grafana, Jaeger e SLOs, IaC com Terraform para cloud (VPC, EC2, RDS). Inclui ArgoCD e error budget.
📝 Lista 3 — Segurança Avançada, Blockchain e Inovação
DevSecOps na pipeline (SAST, SCA, image scanning, Zero Trust, mTLS, OWASP Top 10), smart contract Solidity no Remix para supply chain, criptografia pós-quântica (NIST PQC) e computação quântica, edge computing + IA para manutenção preditiva industrial. Inclui blockchain público vs privado.
